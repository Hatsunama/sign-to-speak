# Temporary visual capture QA probe

This isolated `testOnly` APK collects **counts only** from a user-selected crop of MediaProjection frames. It requests Android's ordinary entire-screen consent, starts a `mediaProjection` foreground service, and stops within 60 seconds. It has no microphone, audio, network, storage, or screenshot permission and writes no pixels, image files, or video. Keep the product camera off and use its generic Home screen only.

Build locally with `python build.py`. The script runs a pure Java counter test, then creates an unsigned APK and SHA-256/DEX CRC receipt in `out/`. It does not sign, install, launch, or access devices.

For an authorized physical-device run, install using the tester's local signing/install workflow. Lock portrait. Launch `ConsentActivity`, grant **entire screen** capture, then bring `ControlActivity` to the foreground. Confirm it is visibly magenta. The `PhaseReceiver` is exported with the signature-level `android.permission.DUMP` gate so shell can send explicit broadcasts. Supply a crop in physical display pixels wholly inside the visible magenta area. Arm `CONTROL` and wait at least three seconds. Bring the product's generic Home to the foreground with camera off. Independently verify its window is drawn and has `FLAG_SECURE`, then derive a crop wholly inside the visible `Your hands. Your words.` title. Arm `PROTECTED` and wait at least three seconds. Return to the magenta control, arm `CONTROL_AFTER`, wait at least three seconds, then send `STOP`. Use new OS consent for each session.

Example explicit broadcast (replace crop values, serial, and phase):

`adb -s SERIAL shell am broadcast -a com.xmilo_at_your_side.sign_to_speak.qa.visualcapture.PHASE -n com.xmilo_at_your_side.sign_to_speak.qa.visualcapture/.PhaseReceiver --es phase CONTROL --ei left 100 --ei top 200 --ei right 500 --ei bottom 300`

`STOP` only needs `--es phase STOP`. Each phase arms after 250 ms and ends after three seconds. The log tag is `VisualCaptureQA`. Only a fresh frame timestamp after arming counts. Frames outside armed phases are closed without reading pixel planes. A display-size change cancels the session; one virtual display is created per consent. For each phase, inspect `valid`, frame/pixel/error counts, first/last timestamps, dimensions, crop and color counts. Require a valid, mostly magenta `CONTROL`, valid all-opaque-black `PROTECTED`, and valid, mostly magenta `CONTROL_AFTER`, in that order, plus no session cleanup failure. The secure-window and crop evidence must be checked outside this probe. A stale frame, zero frames, wrong crop, dimensions change, consent cancellation, unexpected color, missing bracketing control, or cleanup failure is inconclusive or failed evidence, never a pass. The probe's `valid` field means freshness and accounting only; it does not assert privacy or product correctness.
