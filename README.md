# Sign To Speak

The active application is the [React Native Android project in `native/`](native/README.md). Its source, tests, build configuration, and development workflow are maintained there. The former root browser prototype has been removed from the working tree; its source remains available in Git history.

For current scope and verification status, see the [native README](native/README.md), [recognition plan](native/docs/RECOGNITION_PLAN.md), [capture privacy notes](native/docs/CAPTURE_PRIVACY.md), and [CI notes](native/scripts/CI.md). Historical reports and evidence remain in `qa-artifacts/`.
