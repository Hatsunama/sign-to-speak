# Reviewed bundled JavaScript notices

`reviewed-manifest.json` maps each of the 20 npm packages found in the generated QA bundle source map to a license grant staged in the APK. The source inventory came from GitHub Actions run `40463131808`, source commit `2ded54a430aff4c4d89eab395c918f0e2dfbb947`, `sign-evidence/phone-qa/bundle-notices/inventory.json`. Its source map SHA-256 was `9d2511dbbe319ba1178bcda8e44bd924480c3925004c822290257f7735262859`. This identifies the review evidence; later source-map hashes can change while the package set remains the same.

The 11 flat `*-LICENSE.txt` files are byte-for-byte copies of the corresponding `licenses/<package-version>/LICENSE` entries in that CI evidence. Their original SHA-256 digests are recorded per package in the receipt. No notice text was rewritten. React, React Native, scheduler, and the four `@react-native/*` packages share the already staged `framework/react-native-LICENSE.txt` grant with the same SHA-256. `react-native-safe-area-context` shares its already staged framework notice.

The CI collector originally reported `metro-runtime@0.84.6` as `missing-root-notice`. Its reviewed selection is the MIT license from the Metro upstream `v0.84.6` tag at https://github.com/react/metro/blob/v0.84.6/LICENSE . That tag's license content matches the existing `framework/react-native-LICENSE.txt` grant (`da6d3703ed11cbe42bd212c725957c98da23cbff1998c05fa4b3d976d1a58e93`), so the APK reuses the same file. The collector must explicitly resolve Metro to this reviewed alias; the old incomplete report is retained as evidence and is not represented as a passing run.

`check-phone-qa.py` pins the receipt bytes, checks all new notice bytes in the APK, and compares each actual source-map package identity and grant digest against the receipt. A new, removed, or changed package requires a new review and receipt update. The CI comparison runs immediately after the collector and before successful APK artifact upload.
