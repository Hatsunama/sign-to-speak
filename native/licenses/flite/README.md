# Historical Flite source notices

These files document the retired Flite source integration and its provenance. The tracked Flite runtime, JNI bridge, Java request class, and source tests were removed on 2026-10-26 during migration to Pocket TTS. Statements in the preserved notice and audit files describe that historical build, not the current Android package. The active license asset mapping excludes this directory; Pocket assets and notices are audited separately.
