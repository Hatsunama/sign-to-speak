### Failures and root repairs

- Stop previously could not reach request-factory preparation: the worker had no cancellable request until after bundled model copying and verification. Tests-first commit `d97e9af` compiled against the old API and reproduced ignored preparation cancellation. `SpeechSession.Factory.newRequest(BooleanSupplier)` now receives the job generation/lifecycle predicate; `SpeechOwner` passes it to `PocketModelStore.prepare`. Copying and cached hashing share cancellation checks before and after bounded reads, with checks before publication/return. Ownership, atomic replacement/rollback, private verified cache and single-worker retirement remain. Tests cover cancellation, no stale synthesis/playback, owned staging cleanup, retained private bytes and explicit retry. A cancelled job is not removed early to permit overlapping models.
- The APK gate previously accepted a native library at a 4 KiB ZIP offset and skipped ELF checks for additional libraries. Four behavioral RED assertions used real stored ZIP fixtures. `check-pocket-apk-elf.py` now verifies every library in the requested isolated ABI, ELF identity/LOAD alignment and actual local ZIP data offset. Pocket-specific SONAME/dependency/export checks remain; ordinary framework libraries do not inherit Pocket export restrictions. Debug x86_64 and phone ARM64 final APKs both passed with all 15 native libraries inspected. The emulator caller shares this gate, but no new emulator runtime result is claimed.
- Expanding extraction exposed an unsafe Windows drive-qualified basename. A guarded fixture failed before the path restriction; no external write occurred. Native names containing `:` are now rejected before extraction, alongside nested paths, unexpected ABIs and retired Flite artifacts. TensorFlow Lite remains allowed.
- A poll-count cache test did not prove cancellation inside hash reads. Its claim was narrowed. The controlled copy and phone tests now require exactly one read after cancellation. The parent independently removed only the shared helper's two read guards in a private source copy: the stronger host assertion failed, while exact production passed. No obsolete compatibility fixture remains in the current tests.

## Result and intentional behavior changes

Bundled Pocket TTS English 18M/Alba replaces Flite. The retired production engine/source is removed with no hidden fallback. Original app code remains Apache 2.0; upstream runtime notices and CC BY 4.0 model/Alba attribution are retained. Source/configuration/weights/tokenizer/voice are pinned in [PINNED_SOURCES.txt](../vendor/pocket-tts-runtime/PINNED_SOURCES.txt) and the [audition manifest](../vendor/pocket-tts-audition/manifest.json). The app has no service inference API or INTERNET permission.

The Hatsu renderer, styling, intro and rear/front camera implementation are unchanged. Voice and input guidance are intended user-visible changes. Pocket emits 24 kHz mono PCM16; the protected player and drain calculation now use that contract. Flite's original 16 kHz generation/playback agreed: this was a replacement-engine migration, not proof that the old voice had a rate defect.

Input remains bounded to 256 UTF-16 units, 512 UTF-8 bytes and 128 prepared model tokens, with a 30-second PCM budget. Supported accented text passes to native validation; unsupported tokenizations are visibly rejected with the draft retained. The app does not provide unrestricted multilingual or long-document speech.
