# Phase 1 model admission — bounded evidence

Checked 2026-10-25 for the research candidates below; current speech status updated 2026-10-26. This is an admission record for the offline, free, Apache-2.0-original-code Android product, not a claim of model quality or a release license opinion. The bounded Pocket TTS 18M/Alba package now executes on Samsung under the [exact-source checkpoint](POCKET_SPEECH_CHECKPOINT_20261026.md), with selected weights/voice/tokenizer and notices in the QA APK. It has **not** passed owner listening, long-text, resource, two-phone or full release acceptance. No recognition, continuous sentence or reply-ASR model is admitted to production. The October 25 research observations below predate Pocket integration; a branch name or an upstream partial hash is not a pinned artifact. Nothing here authorizes hosted inference or an app network permission.

## Speech path finding

The [Kokoro publisher example](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/README.md) installs eSpeak NG and uses [Misaki](https://github.com/hexgrad/misaki). Misaki's own [Apache-2.0 license](https://github.com/hexgrad/misaki/blob/main/LICENSE) applies to its code; its [English example](https://github.com/hexgrad/misaki) shows `fallback=None`, while its [fallback implementation](https://github.com/hexgrad/misaki/blob/main/misaki/espeak.py) invokes eSpeak. Misaki's Python English dependency list includes `phonemizer-fork` and `espeakng-loader`; a `fallback=None` call does **not** prove an Android distribution excludes those transitive components. [eSpeak NG](https://github.com/espeak-ng/espeak-ng) states GPL-3.0-or-later. Its engine, data and compiled/derived assets must be inventoried individually. A GPL component in the APK requires an intentional obligations decision; the product's Apache original-code policy does not erase that license.

[sherpa-onnx's Kokoro C API example](https://github.com/k2-fsa/sherpa-onnx/blob/master/sherpa-onnx/c-api/docs/tts.dox) explicitly points to `model.onnx`, `voices.bin`, `tokens.txt` and `espeak-ng-data`. Its [Android TTS example](https://github.com/k2-fsa/sherpa-onnx/blob/master/android/SherpaOnnxTtsEngine/app/src/main/java/com/k2fsa/sherpa/onnx/tts/engine/TtsEngine.kt) follows that package. The sherpa project has [documented its eSpeak/piper-phonemize license conflict and planned removal](https://github.com/k2-fsa/sherpa-onnx/issues/3731). An Apache license on sherpa's own repository therefore cannot admit a Kokoro APK assembled from those assets. Recent removal work is not evidence that a selected released Kokoro Android bundle runs correctly without them.

A responsible GPL-free Kokoro comparison would use a pinned permissive English grapheme-to-phoneme implementation and lexicon, disable eSpeak fallback, inventory all dependencies/assets, and compare phoneme tokens and PCM for names, numbers, abbreviations, punctuation, unseen words and short replies. Unknown words must be visibly rejected or corrected. Then measure phone audio, memory, load time, cancellation and long-text chunking. A desktop `fallback=None` example alone cannot establish Android feasibility. The owner's rejection of the earlier Flite voice is historical; current Pocket voice acceptance remains open.

[Supertonic's official card](https://huggingface.co/Supertone/supertonic) identifies MIT **sample code** and a separate [OpenRAIL-M model license](https://huggingface.co/Supertone/supertonic/blob/main/LICENSE). It is a research alternative with a potentially simpler text path, but the actual weights/voice styles and license duties still need a review. Do not substitute that license for Apache 2.0 or choose it silently to avoid Kokoro's GPL issue. OpenRAIL-M duties need a deliberate distribution decision if this option is chosen. That choice does not block the [Pocket TTS/Alba experiment](POCKET_TTS_FEASIBILITY.md): its selected MIT code and CC BY model/voice have ordinary notice and attribution obligations, with no eSpeak dependency.

## Small exit experiments and true blockers

1. **Speech, current partial gate:** [Pocket TTS 18M/Alba](POCKET_SPEECH_CHECKPOINT_20261026.md) now has an exact QA package, passing full Android/component CI and bounded Samsung playback. Finish the owner's fixed listening set, long-text quality, Seeker, performance/soak and privacy/notice acceptance before calling it a release speech package. For any Kokoro comparator, freeze a single ONNX/English-voice package and all files/revisions/hashes; inspect conversion origin, tokenizer/G2P, native libraries and notices, then test a no-eSpeak route on a fixed listening set. A GPL or OpenRAIL-M distribution decision is never implicit.
2. **Signing video, existing harness:** use only licensed annotated RGB clips. Keep private ASL Citizen files and derivatives outside Git/CI/APK. Verify the 543-point named mapping and exact label file, then run the current [validator/scorer](../scripts/recognition-benchmark.py) with predictions from real inference; record model/code/clip hashes and overlap limits. Existing synthetic inference is operator evidence only.
3. **Sentence translation:** use the identified CC BY-SA corpus candidates to freeze lawful reference video, and separately establish deployable weights and training provenance. The Apache-labelled [sign-language-bridge adapter](https://huggingface.co/mamounyosef/sign-language-bridge) uses How2Sign/OpenASL and a 2B Qwen base; its model card does not prove unrestricted training-media rights, useful accuracy or Android export. A bounded desktop direct-video spike can test whether a candidate retains facial/body signals and sentence meaning; no phone or broad training commitment is warranted before that artifact/rights gate.
4. **ASR:** freeze one exact Vosk small-English archive plus a Whisper comparator, inspect licenses per archive and runtime, then use a small transcribed audio set to establish phone memory/latency and error patterns. Published WER is not this app's WER.

**Gate exit:** the isolated, continuous, TTS and ASR slots each need an exact artifact/engine/asset bill of materials, rights to the model *and* evaluation inputs, verified hashes, input/output contracts and measured Android execution. Pocket has bounded Android and Samsung evidence, but a fully accepted natural-speech package remains blocked by owner quality, long-text, resource and privacy gates. A capable Android continuous-ASL model with admitted training provenance is also absent. Licensed sentence video exists. The [earlier Pocket feasibility note](POCKET_TTS_FEASIBILITY.md) preserves the proposal that preceded integration. No recorded-video result establishes live conversational performance; no Deaf recruitment is required for this gate.
